How it was built

Five versions

The rule

Opening-night info only

Every version is backtested on every rookie class since 1990 using only what was known before the season: draft slot, college numbers, teammates, last season's record, preseason minutes, health.

The honest test

21 fell back to 19

Searching for extra factors got the backtest to 21. Hiding one season at a time and predicting it blind brought it back to 19, so the extras were luck and were thrown out.

The voters

31 / 37 with hindsight

Shown a rookie's real full season, the voter model names the actual winner 31 times out of 37. Before the season, the stats have to be projected, which is where the 10,000 simulations come in.
